https://marthajcaro.github.io/Portafolio-Martha-Caro-Mu-oz/

## 💻 Características

- **Diseño Tecnológico (Cyber UI):** Interfaz oscura con detalles en neón (cian y violeta) y fondos de flujo de datos animados.
- **Navegación Interactiva:** Carrusel circular infinito para explorar las tarjetas de información mediante botones o teclado.
- **Efectos Visuales Personalizados:** Retrato renderizado con efecto de puntillismo digital mediante Canvas.
- **Totalmente Responsivo:** Adaptable a pantallas de escritorio, tablets y dispositivos móviles (incluye soporte para gestos táctiles tipo "swipe").
- **Sintaxis de Código:** Bloques de presentación estilizados como consola de desarrollo.

## 🛠️ Tecnologías utilizadas

- **Estructura:** HTML5 semántico.
- **Estilos:** CSS3 (Variables nativas, CSS Grid, Flexbox, animaciones `@keyframes`, Glassmorphism).
- **Lógica:** Vanilla JavaScript (Manipulación del DOM, eventos táctiles, lógica de carrusel circular).
- **Iconos:** Devicon para representación de lenguajes y herramientas.
